# Clases y modelo de objetos

Este directorio contiene proyectos y ejercicios de programación orientada a objetos (POO) en Python. Aquí se exploran los conceptos fundamentales para representar problemas mediante clases y objetos.

## Contenidos

- Definición de clases y creación de objetos
- Atributos y métodos
- Inicialización de objetos con `__init__`
- Encapsulación y colaboración entre objetos
